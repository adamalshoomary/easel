Install in Claude Code

Open in the Claude Code app Open Claude Code in a terminal

Claude Code opens with the install line typed in. Press Enter to install easel. If nothing opens, paste this line into Claude Code:

Install easel from https://github.com/adamalshoomary/easel.

You need

  • Claude Code on a paid Claude plan
  • The Claude in Chrome extension, signed in
  • Python 3.8 or newer
  • macOS, Windows or Linux

Then run it

Open a new Claude Code chat in your notes folder. Run this command with your own unit codes and Canvas address:

/easel IFB201 IFB220 --canvas https://canvas.qut.edu.au

Later runs need only the unit codes. On the first run, if Chrome shows a box about other apps and services on this device, click Allow. If Canvas shows its sign-in page, sign in.

Each unit gets one folder

ABC123 Design Thinking/
├── INDEX.md            next due date, every assessment, every week
├── 1 Course Info/      staff, groups, announcements, Inbox
├── 2 Assessments/      brief, rubric, your files, mark, feedback; Grades.md
├── 3 Weeks/            one note per week
└── Files/              attachments, submissions, feedback PDFs, transcripts, slide text

Other ways to install

One command in a terminal

macOS or Linux:

curl -fsSL https://github.com/adamalshoomary/easel/releases/latest/download/install.sh | sh

Windows, in PowerShell:

irm https://github.com/adamalshoomary/easel/releases/latest/download/install.ps1 | iex

With Node.js, on any system:

npx skills add adamalshoomary/easel -g

If something stops

  • Claude says a safety check stopped the browser step. Open a new chat in your notes folder and run the same command again.
  • Chrome is not connected. In Claude Code, type /chrome and choose Enabled by default, then run the command again.
  • Canvas asks you to sign in. Sign in in the Chrome tab easel opened. easel carries on when you are in.
  • A read failed. The summary says INCOMPLETE and names the part. Your notes keep the last good copy. Run easel again later.

Privacy

  • easel runs on your computer. Canvas data goes from your Chrome tab to your notes folder.
  • easel only reads Canvas. When it opens a feedback file, Canvas marks the feedback as seen.
  • Claude sees the folder paths, the Canvas tab address and each run's summary, which can name assessments, new marks and your average on marked work.
  • easel never changes, moves or deletes a file it did not create. Notes you edit stay as you left them.
