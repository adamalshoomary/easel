easel

Your Canvas units, as clean Markdown notes.

Weeks, assessments, rubrics, marks, feedback, grades, lecture transcripts and slides, in one folder per unit. For Obsidian or any Markdown app. Run it again any time: your own notes stay.

IFB220 Introduction to AI/
├── INDEX.md          next due date, every assessment
├── 1 Course Info/    staff, groups, announcements, Inbox
├── 2 Assessments/    brief, rubric, mark, feedback
│   └── Grades.md     the mark you need for each grade
├── 3 Weeks/          one note per week
└── Files/            your files, feedback PDFs,
                      transcripts, slide text

Install in Claude Code

One click. Claude Code opens with the install line typed in. Press Enter and you are done.

Open in the Claude Code app → or open Claude Code in a terminal
Install easel from https://github.com/adamalshoomary/easel.
  • Claude Code on a paid plan
  • Claude in Chrome, signed in
  • Python 3.8 or newer
  • macOS, Windows or Linux
Other ways to install

macOS or Linux:

curl -fsSL https://github.com/adamalshoomary/easel/releases/latest/download/install.sh | sh

Windows, in PowerShell:

irm https://github.com/adamalshoomary/easel/releases/latest/download/install.ps1 | iex

With Node.js, on any system:

npx skills add adamalshoomary/easel -g

Then run it

Open a new Claude Code chat in your notes folder. Type your unit codes and your Canvas address.

❯/easel IFB201 IFB220 --canvas https://canvas.qut.edu.au
Later runsType the unit codes only. The Canvas address and the folder are kept from the first run.
First runIf Chrome asks about other apps and services on this device, click Allow. If Canvas shows its sign-in page, sign in.
If a safety check stops itRun the same command again in a new chat.
