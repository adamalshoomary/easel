easel

Your Canvas units, as clean Markdown notes.

Open in the Claude app Open in a terminal

Claude Code opens with the install line typed in. Press Enter to install easel.

If nothing opens, paste this line into Claude Code:

Install easel from https://github.com/adamalshoomary/easel.

Then

Open a new Claude Code chat in your notes folder. Then run this command with your own unit codes and Canvas address:

/easel IFB201 IFB220 --canvas https://canvas.qut.edu.au

Each unit gets one folder

IFB220 Introduction to AI/
├── INDEX.md
├── 1 Course Info/
├── 2 Assessments/
├── 3 Weeks/
└── Files/

You need Claude Code on a paid plan, the Claude in Chrome extension and Python 3.8 or newer.
